# DİNÇMAK FOCUS · Safety 4.0 Bootcamp

AİMSAD Safety 4.0 Bootcamp laboratuvar föylerinin DİNÇMAK FOCUS 3 eksen CNC freze makinesine göre
doldurulmuş hâli ve makinenin Safety 4.0 bakışıyla SWOT analizi.

| Dosya | İçerik |
|---|---|
| [`2.1 lab_foyleri_genel_dolu.pdf`](2.1%20lab_foyleri_genel_dolu.pdf) | Lab 1-7 föyleri, genel sürüm (şişeleme hattı) |
| [`2.2 lab_foyleri_paketpro_dolu.pdf`](2.2%20lab_foyleri_paketpro_dolu.pdf) | Lab 1-7 föyleri, PaketPro 3000 sürümü (paketleme makinesi) |
| [`2.3 lab_foyleri_dincmak_focus_dolu.pdf`](2.3%20lab_foyleri_dincmak_focus_dolu.pdf) | Lab 1-7 föyleri, DİNÇMAK FOCUS sürümü (Safety Function Map, Zone/Conduit, Risk Register, Secure Architecture, Vulnerability Decision, Incident Workflow, AI Fail-Safe Decision) |
| [`SWOT.md`](SWOT.md) | SWOT analizi, TOWS stratejileri, öncelikli eylemler ve kaynaklar |
| [`tools/fill_dincmak.py`](tools/fill_dincmak.py) | Boş genel föy şablonunu doldurup PDF'i üreten betik (PyMuPDF) |

PDF'i yeniden üretmek için:

```bash
python tools/fill_dincmak.py "2.1. lab_foyleri_genel.pdf" "2.3 lab_foyleri_dincmak_focus_dolu.pdf"
```

> Bu bir eğitim çıktısıdır; resmî denetim, uygunluk değerlendirmesi veya CE/mevzuat uygunluğu garantisi değildir.
